## 4. Known limitations (honest)

1. **No regional horizon.** PGDA products 90/78 are unreachable from this sandbox; every
   horizon is LOCAL (landing-centered) and labeled as such in UI and reports. The metadata
   model is ready for a real regional product; nothing is fabricated.
2. **Constant frame correction.** ME/PA→IAU is a planning-grade constant rotation with
   disclosed residual ≤0.0039° (~120 m), validated 2020–2035 only; outside that window the
   analysis is blocked, not extrapolated. Not a rigorous time-dependent transformation.
3. **SPICE re-validation not re-run here.** Kernels are absent in this checkout; the 4
   kernel-gated pytest tests skip (reported as skipped). The optional CI job fetches
   checksummed mirrors and runs them for real; it fails loudly if the fetch fails.
4. **CI not yet executed on a GitHub runner.** Every command in the workflow was verified
   locally; first runner execution may surface environment deltas (Playwright deps, mirror
   availability). The quality job has no external downloads beyond npm/PyPI.
5. **Cancellation is coarse.** A running synchronous computation cannot be interrupted
   mid-loop; cancellation terminates and respawns the worker, re-posting still-wanted
   requests. With a 40 ms debounce this is rare and bounded (windows compute in ≲1 s).
6. **Headless-renderer quirks.** Under SwiftShader, screenshots with an open modal can hang
   (the scenario-D capture is best-effort; assertions are the verification), terrain init
   is occasionally slow, and single-process Chromium forbids mid-run context closes.
   Real-GPU behavior is untested here.
7. **Progress fractions are phase weights**, not measured timing (documented as such).
8. **Energy/battery remains an energy-balance model** — no thermal, radiation, dust,
   degradation, or heater loads; DTE remains geometric LOS, not an RF link budget.
9. **Artemis context is a snapshot** (NASA 2026-10-23) and will need refresh; the 2024
   candidate list is explicitly not an Artemis IV selection.
